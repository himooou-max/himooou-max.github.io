# Hyemi — Design Portfolio

Platform UX/UI, Brand Identity & Graphic Design.

## Preview locally

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

## Files

- `index.html`: portfolio layout, styles, and motion.
- `media/`: images, videos, and project assets.

YouTube embeds keep their original links. The repository is private; website hosting and access are configured separately.
